# 🚀 Ahmed Zaki | Front-End Developer Portfolio

A high-performance, responsive personal portfolio built with **React** and **Tailwind CSS**. Designed to be data-driven and fully automated.

**🔗 Live Demo:** [ahmedzaki.me](https://ahmedzaki.me)

---

### 🌟 Key Features
- **🌍 Multi-language:** English & Arabic (LTR/RTL) using `i18next`.
- **🌓 Dark/Light Mode:** Full theme support with persistent settings.
- **⚙️ Data-Driven:** Entirely managed via JSON for easy updates.
- **📈 Analytics:** Integrated with `Google Analytics 4` for tracking.
- **⚡ Optimized:** High performance using `useMemo` and Skeleton Loaders.
- **✉️ Contact Form:** Real-time delivery via `EmailJS` & `React Hook Form`.

### 🛠 Tech Stack
- **Core:** React (Vite), React Router.
- **Styling:** Tailwind CSS.
- **Tools:** i18next, EmailJS, React-GA4.
- **Deployment:** Vercel.

### 🚀 Installation
1. `git clone https://github.com/ahmedzaki-me/Portfolio.git`
2. `npm install`
3. `npm run dev`
