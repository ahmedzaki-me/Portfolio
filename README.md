# Ahmed Zaki | Full Stack Developer Portfolio

A high-performance, bilingual personal portfolio built with **React 19**, **Vite 7**, and **Tailwind CSS 4**, showcasing end-to-end full-stack work across **React / Next.js** and **Node.js / Express / MongoDB / PostgreSQL**.

**Live Demo:** [ahmedzaki.me](https://ahmedzaki.me)

---

### Key Features
- **Multi-language (EN / AR):** Instant English & Arabic (LTR/RTL) switching powered by bundled `i18next` translations.
- **Dark / Light Mode:** Persistent theme support with an optimized starfield `<canvas>` background.
- **Data-Driven Projects:** Case studies and tech stacks structured in `src/data/projects.json`.
- **Product Analytics:** Integrated with **PostHog** for route pageviews and event tracking.
- **Performance Optimized:** Route-level `React.lazy` code splitting, manual vendor chunks, React Compiler, and WebP assets.
- **Contact Form:** Validated via `React Hook Form` with dynamically loaded `@emailjs/browser` delivery.

### Tech Stack
- **Core:** React 19, Vite 7, React Compiler, React Router 7
- **Styling:** Tailwind CSS 4
- **Tools & Services:** i18next, React Hook Form, EmailJS, PostHog, Cloudflare Pages

### Installation
1. `git clone https://github.com/ahmedzaki-me/Portfolio.git`
2. `npm install`
3. Copy `.env.example` to `.env` and fill in your keys
4. `npm run dev`
